Java Spring Boot từ con số 0 cho dev Angular

Lộ trình ước lượng khoảng 12 tháng (10–15 giờ/tuần) từ chưa biết Java tới mức senior cho backend ngân hàng, bảo hiểm — 11 giai đoạn, mỗi giai đoạn có thứ tự học và lý do, so sánh với Angular/TypeScript, khác biệt phiên bản, nguồn học, bài tập, dự án, tiêu chí qua cửa; kèm 4 dự án xuyên suốt, lỗi người từ Frontend hay mắc và cách nhận biết level.

Trang này dành cho người đã làm Angular/TypeScript vài năm nhưng chưa từng viết Java hay Spring Boot, muốn đi tới mức làm backend được ở dự án ngân hàng, bảo hiểm và qua phỏng vấn. Câu hỏi phỏng vấn đi kèm chia theo level: Newbie · Junior · Middle · Senior.

Tài liệu học theo level — học cái nào trước, đọc phần nào, sách nào đáng mua, tài liệu nào đã cũ: Tài liệu Java theo level. Mục Nguồn học trong từng giai đoạn bên dưới có link bấm được.

Phiên bản chuẩn (đối chiếu 15/11/2026): Java 25 LTS và Spring Boot 4.1 (Spring Framework 7, Spring Security 7, Hibernate 7, Jackson 3). Spring Boot 3.5 đã hết hỗ trợ cộng đồng từ 30/06/2026; 4.0 hết hỗ trợ cuối 12/2026. Ngân hàng Việt Nam còn chạy rất nhiều hệ thống Java 8/11/17/21 + Spring Boot 2.x/3.x, nên mỗi giai đoạn có mục Phiên bản cần để ý chỉ ra chỗ khác nhau — để bạn không học nhầm tài liệu cũ, mà vẫn đọc được code cũ.

Môi trường: macOS, JDK 25 (bản Eclipse Temurin), cài qua SDKMAN (sdk list java rồi sdk install java <bản 25 tem>) hoặc tải từ adoptium.net; IntelliJ IDEA; Maven (dùng ./mvnw có sẵn trong project); Docker Desktop cho database và Kafka. Tạo project Spring Boot ở start.spring.io.

Hai trang Java đã có trong app vẫn dùng được song song: Java theo lộ trình 58 tuần (xếp 261 câu theo tuần) và Checklist Java Spring Boot (bản checklist gốc của bạn đã rà soát). SQL học theo trang riêng SQL từ con số 0 — mục "Học song song với SQL" ở cuối trang chỉ cách ghép.

Cách dùng trang này

  • Đi đúng thứ tự và chỉ sang giai đoạn sau khi đạt mục Qua cửa — tiêu chí là việc làm được, không phải số trang đã đọc.
  • Mỗi tuần (~12 giờ): 3 giờ đọc/xem → 6 giờ tự code → 2 giờ dự án → 1 giờ ôn câu hỏi trong app (tự trả lời thành tiếng rồi mới xem đáp án).
  • Viết test từ tuần 2, không đợi tới giai đoạn testing. Thói quen này quan trọng hơn mọi framework.
  • Mọi con số thời gian trên trang là ước lượng cho 10–15 giờ/tuần (lấy trung bình 12). Học 10 giờ/tuần thì cộng khoảng 20%, 15 giờ/tuần thì trừ khoảng 20%.

Ký hiệu nguồn: ✅ chắc chắn có thật và miễn phí · 💰 trả phí · ⚠️ có thật nhưng nội dung/phiên bản cần kiểm tra trước khi dùng.

Tổng khoảng 53 tuần (~12 tháng), ~640 giờ — ước lượng. Sau giai đoạn 5–7 (tháng thứ 7–8) bạn đủ kiến thức ứng tuyển Junior; sau giai đoạn 9 đủ kiến thức trả lời phỏng vấn Middle. Senior thật cần thêm vài năm làm production — lộ trình cho bạn điều kiện cần và câu chuyện để kể, không thay được kinh nghiệm.

Bốn thay đổi tư duy khi từ Angular sang Spring Boot

  1. Nhiều thread thật, không có event loop. Code Spring MVC viết tuần tự, chặn chờ database là bình thường; đổi lại, mọi field của bean singleton đều bị nhiều request dùng chung cùng lúc.
  2. Server là nơi quyết định cuối. Validator, route guard, ẩn nút ở Angular là trải nghiệm; validate, phân quyền, kiểm tra quyền sở hữu phải làm lại ở API.
  3. Dữ liệu và transaction là trung tâm. Bug nguy hiểm nhất của backend ngân hàng không nằm ở giao diện mà ở trừ tiền hai lần, mất cập nhật, đối soát lệch.
  4. Vận hành là một phần công việc. Log, metric, cấu hình theo môi trường, khởi động lại an toàn, xử lý sự cố lúc 2 giờ sáng — không có "deploy lại bundle là xong".

Giai đoạn 1 — Core Java (tuần 1–8)

Mục tiêu: viết Java thuần đúng kiểu Java (không phải "JavaScript có kiểu"), có test.

Chủ đề theo thứ tự

  1. Môi trường: JDK, javac/java, IntelliJ, cấu trúc project Maven (pom.xml, src/main/java, src/test/java), ./mvnw test. JDK là bộ công cụ phát triển, JVM là máy ảo chạy bytecode.
  2. Cú pháp và kiểu: 8 kiểu nguyên thuỷ, String, điều khiển luồng, method, mảng, var, switch expression, text block.
  3. OOP: class/object, constructor, đóng gói (private + method), kế thừa, interface vs abstract class, đa hình, overload/override, equals/hashCode, record, enum, sealed.
  4. Exception: checked vs unchecked, try-with-resources, exception tự định nghĩa.
  5. Collections và Generics: List/Set/Map/Deque, chọn collection, bất biến (List.of), generic và wildcard cơ bản.
  6. Lambda, Stream, Optional: functional interface, method reference, map/filter/collect/groupingBy, Optional dùng cho kiểu trả về.
  7. Java hiện đại: record pattern, pattern matching trong switch (Java 21), sequenced collections; Java 25: compact source files, flexible constructor bodies.
  8. I/O cơ bản: Path, Files, đọc file theo luồng, charset UTF-8.
  9. JUnit cơ bản — bản 6 đi cùng Spring Boot 4, cách viết test giống JUnit 5 (từ tuần 2 trở đi, song song mọi chủ đề) và debugger của IntelliJ.

Vì sao thứ tự này: có môi trường chạy được trước → cú pháp và kiểu (khác TS nhiều nhất ở số và so sánh) → OOP vì mọi thứ trong Java là class và Spring dựa trên interface/kiểu → exception cần trước khi đụng I/O và API → collection/generic là nền dữ liệu → stream cần cả collection lẫn generic → tính năng hiện đại làm gọn code đã biết → I/O dùng cả exception lẫn stream.

Phiên bản cần để ý

  • Java 8 (rất nhiều ở ngân hàng): chưa có var (10), record/text block (16–17), List.of (9); code cũ dùng Date/Calendar thay java.time.
  • Java 17 → 21: pattern matching cho switch và record pattern final ở 21; virtual thread final ở 21.
  • Java 21 → 25: stream gatherers (24), virtual thread không còn bị "pin" bởi synchronized (24), scoped values và compact source files final ở 25. Structured concurrency vẫn là preview ở 25 — không dùng trong production.
  • Tài liệu Oracle Java Tutorials (docs.oracle.com/javase/tutorial) ghi rõ viết cho JDK 8 — chỉ đọc phần khái niệm.

Nguồn học

  • ✅ dev.java — Learn (dev.java/learn): tutorial chính thức, cập nhật theo bản mới.
  • ✅ OpenJDK JEPs (openjdk.org/jeps): trạng thái chính thức preview/final của từng tính năng.
  • ✅ Exercism — Java track (exercism.org): bài tập có mentor, hợp để luyện cú pháp tuần 1–4.
  • ✅ JUnit User Guide (docs.junit.org): JUnit 6, bản Spring Boot 4 dùng; cách viết test giống JUnit 5.
  • 💰 Effective Java, 3rd edition (Joshua Bloch): viết cho Java 9 nhưng nguyên tắc (equals, bất biến, generic, exception) vẫn là chuẩn.
  • 💰 Head First Java, 3rd edition: dễ đọc cho người mới; ⚠️ kiểm tra bản bạn mua viết cho Java 17 trở lên.
  • 💰 Modern Java in Action (Urma, Fusco, Mycroft): lambda, stream, Optional sâu.

Bài tập

  1. 20 bài Exercism Java (tuần 1–4), mỗi bài commit kèm test.
  2. Bài tập: ngân hàng mini bằng Java thuần — record bất biến, enum, Map, exception nghiệp vụ, Stream gom theo tiền tệ, và test JUnit chứng minh chuyển tiền lỗi không đổi gì — ngân hàng mini bằng record, enum, Map, exception, Stream, JUnit.
  3. Bài tập: đọc file sao kê CSV bằng Java — Files.lines theo luồng, LocalDate và BigDecimal, gom dòng lỗi thay vì dừng cả file, chống trùng mã, tổng theo ngày bằng TreeMap — đọc file sao kê CSV theo luồng, gom dòng lỗi.
  4. Bài tập: value object Money bất biến — cộng trừ cùng tiền tệ, nhân tỉ lệ có làm tròn, phân bổ không mất đồng nào — value object Money bất biến, phân bổ không mất đồng nào.
  5. Bài tập live coding: 8 bài nhỏ hay ra ở vòng code trực tiếp — anagram, ký tự không lặp đầu tiên, two-sum, ngoặc hợp lệ, gộp khoảng, đếm tần suất — viết bằng Java chuẩn và nói ra suy nghĩ — 8 bài live coding hay gặp.

Dự án nhỏ — java-core-lab: gộp bài 2 và 3 thành một repo Maven: import file CSV vào ngân hàng mini, in báo cáo, ≥ 15 test, README ghi 5 chỗ Java khác TypeScript bạn đã vấp.

Qua cửa

  • ○ Tạo project Maven, viết class + record + enum + exception + test mà không cần chép mẫu.
  • ○ Giải 6/8 bài live coding collections, mỗi bài ≤ 20 phút.
  • ○ Giải thích bằng lời: equals/hashCode, checked vs unchecked, String bất biến, Java truyền tham trị, stream lười.
  • ○ Đọc stack trace có Caused by, đặt breakpoint có điều kiện, sửa được một NullPointerException.

Đọc sâu trong app

Từ TypeScript sang Java — kiểu được kiểm tra cả lúc chạy, mọi thứ nằm trong class, number tách thành int/long/double/BigDecimal, không có undefined, == với object · JDK, JRE và JVM khác nhau thế nào? Từ file .java tới lúc chạy — bytecode, classpath, JIT — đi qua những bước nào? · Maven cho người mới vào dự án Java — lifecycle và phase, dependency scope, parent/BOM và dependencyManagement, multi-module, settings.xml trỏ Nexus nội bộ, và Gradle khác gì · 8 kiểu nguyên thuỷ, ép kiểu mở rộng/thu hẹp, tràn số và chia nguyên — vì sao int nhân int có thể làm sai số tiền? · Vì sao String là immutable? == và equals khác gì? StringBuilder, string pool và nối chuỗi trong vòng lặp · Java truyền tham trị hay tham chiếu? Giải thích bằng ví dụ sửa object và gán lại biến bên trong method · Bốn tính chất OOP và nguyên tắc SOLID — giải thích bằng ví dụ thật trong ứng dụng ngân hàng · Interface và abstract class khác nhau thế nào từ Java 8 trở đi — default method, trạng thái, và khi nào chọn cái nào? · Vì sao override equals() thì phải override hashCode()? Record giải quyết thế nào, và bẫy với entity JPA? · Checked và unchecked exception khác nhau thế nào? Thiết kế xử lý lỗi cho ứng dụng Spring Boot ra sao? · Chọn collection thế nào — ArrayList vs LinkedList, HashMap vs LinkedHashMap vs TreeMap, và Set, Queue khi nào? · Generics trong Java — type erasure, wildcard ? extends / ? super (PECS), và vì sao List
