Tài liệu học Java Spring Boot theo level

Bộ tài liệu tốt nhất cho từng level Newbie → Junior → Middle → Senior của lộ trình Java Spring Boot từ con số 0 — học cái nào trước, đọc phần nào, miễn phí hay trả phí, vì sao chọn; mọi link đã kiểm tra ngày 15/11/2026, kèm danh sách tài liệu đã cũ cần tránh (JUnit 5 → 6, Spring in Action viết cho Boot 2, DDIA bản 2).

Trang này gom tài liệu học của lộ trình Java Spring Boot từ con số 0 theo từng level, khớp với bộ câu hỏi Newbie · Junior · Middle · Senior. Mỗi level có một danh sách học chính theo thứ tự — học từ trên xuống, xong cái trước mới sang cái sau — và các danh sách phụ để luyện tập, tra cứu.

Ký hiệu: ✅ miễn phí · 💰 trả phí (không bắt buộc) · ⚠️ cần kiểm tra phiên bản hoặc điều kiện trước khi dùng. Link kiểm tra ngày 15/11/2026; một số trang (Baeldung, O'Reilly, Oracle) chặn công cụ kiểm tra tự động nhưng mở bằng trình duyệt bình thường.

Cách chọn và dùng tài liệu

  1. Mỗi lúc một tài liệu chính. Cột "Học chính" là thứ bạn đọc từ đầu tới cuối; mọi thứ khác chỉ để tra cứu khi vướng.
  2. Thứ tự tin cậy: tài liệu chính thức (docs.spring.io, dev.java) → khoá học của chính hãng (Spring Academy) → sách → blog của chuyên gia có tên tuổi → video → bài tổng hợp, câu trả lời của AI.
  3. Luôn kiểm tra phiên bản trước khi đọc: chuẩn của lộ trình là Java 25, Spring Boot 4.1, Spring Framework 7, JUnit 6, namespace jakarta. Bài viết dùng javax.*, WebSecurityConfigurerAdapter hay @MockBean là đã cũ — đọc lấy ý, đừng chép code.
  4. Đọc xong phải làm: mỗi chương hoặc mỗi bài hướng dẫn kết thúc bằng một commit trong repo của bạn. Đọc mà không gõ thì một tuần sau gần như quên hết.
  5. Ngân sách: chỉ dùng phần ✅ vẫn đủ tới Middle. Nếu chỉ mua một cuốn sách cho cả lộ trình, mua Designing Data-Intensive Applications bản 2 (xem level Senior).

Tài liệu đã thay đổi — tránh đọc nhầm bản cũ

Tài liệu Tình trạng (15/11/2026) Nên làm gì
JUnit JUnit 6 phát hành 30/9/2025 và là bản Spring Boot 4 dùng. Cách viết test (@Test, @ParameterizedTest, assertThrows) giống JUnit 5 Đọc docs.junit.org bản hiện hành; bài viết "JUnit 5" vẫn dùng được cho phần cú pháp
Spring in Action Bản mới nhất vẫn là 6th edition (3/2022), viết cho Spring Boot 2 (javax) — chưa có bản cho Boot 3/4 Không mua mới; nếu đã có thì chỉ đọc khái niệm
Spring Start Here Bản 1 (2021) viết cho Boot 2; bản 2 đang viết dở (MEAP từ 6/2026), dự kiến phát hành đầu 2027 Bản 1 vẫn là sách giải thích nền tảng Spring dễ hiểu nhất — đọc kèm việc đổi javax → jakarta
Designing Data-Intensive Applications Bản 2 (Kleppmann và Riccomini) phát hành đầu 2026 Mua bản 2, không mua bản 2017
Spring Academy Toàn bộ nội dung Pro miễn phí từ 4/2024 Dùng làm khoá học chính ở level Junior
Baeldung Rất nhiều bài, nhưng không ít bài viết cho Boot 2/3 Xem phiên bản ghi ở đầu bài trước khi chép code
Effective Java 3rd edition (2017) vẫn là bản mới nhất Nguyên tắc vẫn đúng; phần cú pháp mới xem dev.java

Newbie

Tương ứng: giai đoạn 1–2 của lộ trình (tháng 1–3). Mục tiêu: viết Java thuần đúng kiểu Java, có test; hiểu HTTP, Git, SQL cơ bản. Câu hỏi: Phỏng vấn Java — Newbie.

Học chính, theo thứ tự

# Tài liệu Loại Học phần nào Vì sao chọn
1 dev.java — Learn ✅ Tài liệu chính thức của Oracle Getting Started → Language Basics → Classes and Objects → Interfaces → Exceptions → Generics → Collections → Lambda và Stream Chính thức, cập nhật theo Java mới nhất — đọc làm khung
2 MOOC.fi — Java Programming I và II ✅ Khoá học của Đại học Helsinki Programming I trong tháng 1, Programming II trong tháng 2–3 Hàng trăm bài tập chấm tự động — cách luyện tay tốt nhất cho người mới; dùng cú pháp Java cũ hơn một chút nhưng nền tảng là một
3 Exercism — Java track ✅ Bài tập có mentor 20 bài đầu, tuần 1–4 Được người thật review miễn phí — học cách viết Java "đúng chất"
4 JUnit User Guide ✅ Tài liệu chính thức Writing Tests: annotation, assertion, @ParameterizedTest Viết test từ tuần 2 là thói quen quan trọng nhất của level này
5 IntelliJ IDEA — Debugging ✅ Tài liệu công cụ Breakpoint, conditional breakpoint, evaluate expression Người từ Frontend quen console.log — debugger là kỹ năng phải tập riêng

Nền backend đi kèm

  • MDN — HTTP ✅ — method, status code, header, CORS (bạn đã biết một nửa).
  • Pro Git ✅ chương 1–3 và Learn Git Branching ✅.
  • SQL từ con số 0 giai đoạn 1–2, tài liệu ở trang Tài liệu SQL theo level.

Sách nếu muốn mua

  • 💰 Head First Java, 3rd edition (2022) — dễ đọc nhất cho người mới, cập nhật tới Java 17.
  • 💰 Modern Java in Action (Urma, Fusco, Mycroft) — đọc phần lambda, stream, Optional nếu muốn sâu hơn dev.java.

Chưa cần ở level này

Spring, JPA, microservices, tinh chỉnh JVM, design pattern sâu — đọc bây giờ chỉ thêm rối.

Junior

Tương ứng: giai đoạn 3–5 (tháng 3–7). Mục tiêu: viết được API Spring Boot hoàn chỉnh và hiểu vì sao nó chạy — bean, request, transaction, lỗi. Câu hỏi: Phỏng vấn Java — Junior.

Học chính, theo thứ tự

# Tài liệu Loại Học phần nào Vì sao chọn
1 Spring Academy ✅ Khoá học chính hãng, có lab trên trình duyệt Các khoá Spring Boot nhập môn và REST API; ⚠️ xem khoá viết cho bản Boot nào Do đội Spring làm, miễn phí toàn bộ từ 4/2024
2 Spring Guides ✅ Bài hướng dẫn ngắn có code Building a RESTful Web Service, Accessing Data with JPA, rồi các bài về validation, security, testing 15–30 phút mỗi bài, luôn cập nhật theo bản mới
3 Marco Behler — Guides ✅ Bài giải thích chuyên sâu Spring Framework explained, Spring Transaction Management: @Transactional in depth Giải thích vì sao — bean, proxy, transaction — rõ nhất trong các nguồn miễn phí
4 Spring Boot Reference ✅ và Spring Framework Reference ✅ Tài liệu chính thức Boot: Core Features, Web, Data, Testing. Framework: Core (IoC container), Web MVC, Data Access (transaction) Nguồn sự thật; mọi tranh luận kết thúc ở đây
5 Spring Data JPA Reference ✅ và Hibernate ORM docs ✅ Tài liệu chính thức Repository, query method, projection; Hibernate: entity state, fetching Hiểu JPA làm gì bên dưới để tránh N+1
6 Spring Security Reference ✅ Tài liệu chính thức Servlet: Architecture, Authentication, Authorization, OAuth2 Resource Server Ngân hàng hỏi bảo mật ngay từ vòng Junior
7 Testcontainers — Guides ✅ Hướng dẫn chính thức Bài cho Spring Boot + PostgreSQL Test với database thật thay vì H2

Xem thêm và tra cứu

  • Dan Vega — YouTube ✅ — Spring Developer Advocate, video theo bản Spring mới.
  • Baeldung ✅⚠️ — tra cứu theo chủ đề; xem phiên bản ở đầu bài.
  • Spring Boot 4.0 Migration Guide ✅ — đọc để biết code cũ trên mạng khác Boot 4 ở đâu.
  • Loda.me ✅⚠️ — blog Spring Boot tiếng Việt, dễ đọc; viết cho Spring Boot 2 nên chỉ lấy khái niệm.

Sách nếu muốn mua

  • 💰 Spring Start Here (Laurentiu Spilca, 2021) — giải thích nền tảng Spring dễ hiểu nhất; viết cho Boot 2, đọc kèm đổi javax → jakarta.
  • 💰 Spring Security in Action, 2nd edition (Spilca, 2024) — viết cho Spring Boot 3: SecurityFilterChain, OAuth2/OpenID Connect.

Chưa cần ở level này

Kafka, Kubernetes sâu, reactive (WebFlux), tinh chỉnh GC.

Middle

Tương ứng: giai đoạn 5–9 (tháng 6–11). Mục tiêu: hiểu cơ chế và biết đánh đổi — JPA và transaction sâu, đồng thời, messaging, bảo mật, test tích hợp. Câu hỏi: Phỏng vấn Java — Middle.

Học chính, theo thứ tự

# Tài liệu Loại Học phần nào Vì sao chọn
1 Blog Vlad Mihalcea ✅ và 💰 High-Performance Java Persistence Blog và sách của chuyên gia Hibernate N+1, batching, locking (optimistic/pessimistic), connection pool, transaction isolation Nguồn sâu nhất về JPA trong thực tế — đúng thứ ngân hàng hỏi kỹ
2 Thorben Janssen ✅ Blog chuyên đề JPA/Hibernate Tra theo vấn đề đang gặp Bài ngắn, đi thẳng vào một vấn đề
3 💰 Effective Java, 3rd edition (Joshua Bloch) Sách Chương về object, class, generics, enum, lambda, exception, concurrency Chuẩn mực viết Java mà người phỏng vấn Middle hay dẫn
4 JEP 444 — Virtual Threads ✅ và Inside Java ✅ Tài liệu chính thức JEP đọc toàn bộ; Inside Java theo dõi hằng tháng Concurrency hiện đại và tin tức từ chính đội Java
5 Confluent Developer — Courses ✅, Apache Kafka docs ✅, Spring for Apache Kafka ✅ Khoá học và tài liệu chính thức Khoá Kafka nhập môn → Kafka docs phần Design → Spring Kafka Messaging là ranh giới Junior/Middle ở hệ ngân hàng
6 microservices.io ✅ Danh mục mẫu thiết kế (Chris Richardson) Saga, Transactional outbox, API gateway, Database per service Từ vựng chung khi thảo luận kiến trúc phân tán
7 OWASP Cheat Sheet Series ✅ và OWASP API Security Top 10 ✅ Tài liệu bảo mật Authentication, Authorization, Input Validation, JWT; API Top 10 Ngân hàng hỏi lỗ hổng cụ thể, không hỏi chung chung
8 Micrometer docs ✅ Tài liệu chính thức Concepts, Observation API Metric và trace cho Spring Boot

Xem thêm và tra cứu

  • Resilience4j ✅ — circuit breaker, retry, bulkhead.
  • JDK Mission Control ✅ và async-profiler ✅ — đo trước khi tối ưu.

Sách nếu muốn mua

  • 💰 Unit Testing: Principles, Practices, and Patterns (Vladimir Khorikov) — khi nào mock, test cái gì.
  • 💰 Java Concurrency in Practice (Goetz và cộng sự, 2006) — nguyên lý vẫn đúng, đọc kèm JEP 444.
  • 💰 Building Microservices, 2nd edition (Sam Newman).

Chưa cần ở level này

Viết framework riêng, GraalVM native image sâu, tinh chỉnh GC chi tiết khi chưa có số đo.

Senior

Tương ứng: giai đoạn 8–11 và liên tục. Mục tiêu: ra quyết định kiến trúc có lý do và số đo; hệ thống tiền đúng; dẫn dắt người khác. Câu hỏi: Phỏng vấn Java — Senior.

Học chính, theo thứ tự

# Tài liệu Loại Học phần nào Vì sao chọn
1 💰 Designing Data-Intensive Applications, 2nd edition (Kleppmann, Riccomini, 2026) Sách Toàn bộ; ưu tiên replication, partitioning, transactions, consistency Nếu chỉ mua một cuốn cho cả lộ trình, mua cuốn này
2 Amazon Builders' Library ✅ Bài viết của kỹ sư Amazon Timeouts, retries and backoff with jitter; Making retries safe with idempotent APIs; Avoiding insurmountable queue backlogs Kinh nghiệm vận hành hệ lớn — áp thẳng vào chuyển tiền, đối soát
3 💰 Fundamentals of Software Architecture, 2nd edition (Richards, Ford, 2025) Sách Đặc tính kiến trúc, các kiểu kiến trúc, trade-off Khung để trả lời "vì sao chọn kiến trúc này"
4 💰 System Design Interview, tập 1 và 2 (Alex Xu) Sách Phương pháp 4 bước, ước lượng tải, các bài mẫu Luyện format phỏng vấn system design
5 martinfowler.com ✅ và ADR ✅ Bài viết, mẫu tài liệu Patterns of Distributed Systems; mẫu ADR của Michael Nygard Ghi quyết định kiến trúc đúng cách
6 Google SRE books ✅ Sách miễn phí Service Level Objectives, Managing Incidents, Postmortem Culture Senior backend phải nói được ngôn ngữ vận hành
7 Jepsen — Consistency Models ✅ Bản đồ mô hình nhất quán Tra cứu khi bàn về isolation và nhất quán Tránh dùng sai thuật ngữ "strong consistency"

Sách nếu muốn mua

  • 💰 Working Effectively with Legacy Code (Michael Feathers) — công việc thật ở ngân hàng là sửa code cũ.
  • 💰 The Staff Engineer's Path (Tanya Reilly) — phần con người của Senior.
  • 💰 Domain-Driven Design Distilled (Vaughn Vernon) — DDD gọn trong 200 trang.

Theo dõi để không lạc hậu

  • Inside Java ✅ và trang JDK 25 ✅ — tính năng mới, tính năng preview.
  • Spring Boot Migration Guide ✅ — mỗi lần lên bản lớn.
