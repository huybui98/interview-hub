Phỏng vấn Java Spring Boot — Junior

38 câu lý thuyết level Junior (Core Java nâng cao, Spring Core, cấu hình, REST, JPA cơ bản, transaction, bảo mật nền, Mockito, Docker, kỹ năng mềm), 5 bài thực hành và 1 dự án; mỗi câu có mức ưu tiên, trả lời ngắn, giải thích sâu, code, bẫy và câu hỏi đào tiếp.

Level thứ hai của bộ câu hỏi đi kèm lộ trình Java Spring Boot từ con số 0 — tương ứng giai đoạn 3–5 (khoảng tháng 3–7). Trước đó: Newbie. Sau đó: Middle · Senior.

Ở level Junior, người phỏng vấn kiểm tra bạn viết được một API Spring Boot hoàn chỉnh và hiểu vì sao nó chạy: bean từ đâu ra, request đi qua đâu, transaction mở ở đâu, lỗi trả về thế nào. Các câu về proxy và @Transactional gần như luôn xuất hiện — kể cả ở vòng Junior của ngân hàng.

Mức ưu tiên: Bắt buộc · Nên biết · Nâng cao. Mỗi câu mở ra có đủ năm phần: ⭐ trả lời ngắn, 📖 giải thích sâu, 💻 code, ⚠️ bẫy, 🔁 câu đào tiếp.

Thuật ngữ mới ở level này

Thuật ngữ Nghĩa ngắn
Bean scope Phạm vi sống của bean: singleton, prototype, request
Proxy (AOP) Object bọc bean để chèn hành vi trước/sau lời gọi
Starter, auto-configuration Gói dependency + cấu hình tự động theo điều kiện
Profile Bộ cấu hình theo môi trường (dev, test, prod)
DTO Đối tượng truyền dữ liệu qua API, tách khỏi entity
Entity, repository Lớp ánh xạ bảng; giao diện truy cập dữ liệu
Transaction Nhóm thao tác cùng thành công hoặc cùng huỷ
ProblemDetail Định dạng lỗi chuẩn RFC 9457 cho REST API
Mock Đối tượng giả trong test

Qua cửa level Junior

  • ○ Trả lời thành tiếng mọi câu Bắt buộc, mỗi câu ≤ 1 phút.
  • ○ Dự án InsureFlow chặng 1: Angular gọi API thật, lỗi trả ProblemDetail có mã, có test.
  • ○ Giải thích bằng ví dụ vì sao @Transactional gọi qua this không chạy.
