Java theo lộ trình Angular → Spring Boot

Nối 12 giai đoạn của lộ trình "Từ Angular sang Spring Boot" (58 tuần) với từng câu trong app — đọc câu nào ở tuần nào, bắt đầu từ nền tảng, đi tới tình huống ngân hàng.

Bộ Java có 261 câu, đi từ nền tảng cho người chuyển từ frontend (JVM, kiểu dữ liệu, IoC, luồng một request) tới senior (transaction, concurrency, Kafka, sự cố production) và thực tế ngân hàng Việt Nam (stored procedure Oracle, MyBatis, JMS/IBM MQ, SOAP, WAR trên WebLogic). Trang này đặt các câu theo đúng 12 giai đoạn của lộ trình "Từ Angular sang Spring Boot": mỗi giai đoạn đọc câu được gợi ý theo thứ tự, làm bài tập (câu có chữ "Bài tập"), rồi mới sang giai đoạn sau.

Đối chiếu ngày 12/11/2026 với Java 25 LTS (Java 27 đã ra 9/2026, không phải LTS), Spring Boot 4.1 (4.2 đang RC), Spring Framework 7, Hibernate 7, Jackson 3.

Bản lộ trình 11 giai đoạn viết lại cho người chưa biết Java, có so sánh với Angular, nguồn học, bài tập và tiêu chí qua cửa: Java Spring Boot từ con số 0.

Cách dùng với lộ trình: câu hỏi ở đây là phần (f) tự kiểm tra mở rộng của mỗi giai đoạn — đọc sau khi đã gõ code, không thay cho việc gõ code. Phần "🏦 Thực tế" của mỗi câu ghi rõ chỗ bạn chưa làm trực tiếp; cập nhật nó mỗi khi làm xong một bài trong dự án InsureFlow.

0. Trước tuần 1 — bản đồ Angular → Spring

  • DI và container — giống Angular nhưng singleton phục vụ nhiều thread IoC và DI khác nhau thế nào? Bean là gì, ApplicationContext khác BeanFactory ra sao, và container tạo một bean qua những bước nào · Dependency injection trong Spring — vì sao constructor injection tốt hơn @Autowired trên field? Nhiều cài đặt, phụ thuộc tuỳ chọn xử lý ra sao? · Bean scope và vòng đời bean — singleton có thread-safe không, prototype trong singleton, và vì sao @Transactional không chạy trong @PostConstruct
  • Interceptor ba tầng — filter, HandlerInterceptor, AOP Một HTTP request đi qua Spring MVC thế nào — từ Tomcat, filter, DispatcherServlet, HandlerMapping, interceptor, argument resolver, message converter tới exception resolver · Filter, HandlerInterceptor và AOP khác nhau thế nào — log request, gắn trace id, kiểm tra tenant đặt ở đâu?
  • ThreadLocal thay cho zone.js — vì sao mất người dùng/traceId khi sang thread khác ThreadLocal trong thread pool — rò dữ liệu giữa request, rò bộ nhớ, mất ngữ cảnh khi async; ScopedValue của Java 25 giải quyết gì · Spring Security xác thực một người dùng thế nào — AuthenticationManager, ProviderManager, AuthenticationProvider, UserDetailsService, PasswordEncoder, SecurityContextHolder; authentication khác authorization ra sao

1. Java core & công cụ (tuần 1–9)

  • Tuần 1 — JVM, project Maven thật JDK, JRE và JVM khác nhau thế nào? Từ file .java tới lúc chạy — bytecode, classpath, JIT — đi qua những bước nào? · Maven cho người mới vào dự án Java — lifecycle và phase, dependency scope, parent/BOM và dependencyManagement, multi-module, settings.xml trỏ Nexus nội bộ, và Gradle khác gì · 8 kiểu nguyên thuỷ, ép kiểu mở rộng/thu hẹp, tràn số và chia nguyên — vì sao int nhân int có thể làm sai số tiền? · public, protected, package-private, private — phạm vi từng cái, và vì sao package-private là công cụ thiết kế bị bỏ quên trong ứng dụng Spring · Java truyền tham trị hay tham chiếu? Giải thích bằng ví dụ sửa object và gán lại biến bên trong method · final, static, finally và finalize — mỗi từ khoá làm gì, và vì sao field static trong Spring bean là nguồn bug? · Vì sao String là immutable? == và equals khác gì? StringBuilder, string pool và nối chuỗi trong vòng lặp · Vì sao Integer a = 127, b = 127 thì a == b là true nhưng với 128 lại false — autoboxing, Integer cache và NullPointerException khi unboxing
  • Tuần 2 — OOP, equals/hashCode, record, enum — học debugger ngay tuần này Bốn tính chất OOP và nguyên tắc SOLID — giải thích bằng ví dụ thật trong ứng dụng ngân hàng · Interface và abstract class khác nhau thế nào từ Java 8 trở đi — default method, trạng thái, và khi nào chọn cái nào? · Vì sao override equals() thì phải override hashCode()? Record giải quyết thế nào, và bẫy với entity JPA? · Mô hình hoá nghiệp vụ bằng record, sealed interface và pattern matching — thay cho if/else và instanceof · Enum trong Java mạnh hơn hằng số thế nào — field, method, hành vi riêng từng hằng, EnumMap/EnumSet, và bẫy EnumType.ORDINAL khi lưu DB · Các method của Object, shallow copy và deep copy — vì sao clone() bị coi là thiết kế hỏng và nên sao chép object thế nào? · Static nested class, inner class, local và anonymous class khác nhau thế nào — và vì sao inner class có thể gây rò bộ nhớ? · Debug Java như người làm thật — đọc stack trace dài (Caused by), breakpoint có điều kiện, exception breakpoint, Evaluate Expression, drop frame, và remote debug vào container (JDWP) an toàn · Overloading và overriding khác nhau thế nào — quy tắc, static/private method, covariant return, và @Override để làm gì? · Thiết kế lớp bất biến trong Java — vì sao quan trọng, làm thế nào cho đúng, và defensive copy · Singleton trong Java — các cách cài đặt thread-safe (enum, holder, double-checked locking), vì sao trong Spring hiếm khi tự viết, và bẫy · Bài tập: thay khối if/else 200 dòng tính phí theo kênh (ATM, Internet banking, quầy, đối tác) bằng Strategy + Spring — thêm kênh mới không sửa code cũ · Constructor trong Java — không kế thừa được, this() và super(), thứ tự khởi tạo static/field/constructor giữa lớp cha và lớp con, và vì sao gọi method overridable trong constructor là bẫy
  • Tuần 3 — Collections, generics Chọn collection thế nào — ArrayList vs LinkedList, HashMap vs LinkedHashMap vs TreeMap, và Set, Queue khi nào? · HashMap hoạt động bên trong thế nào — hash, bucket, resize, treeify — và vì sao không thread-safe? · TreeMap/NavigableMap, PriorityQueue và ArrayDeque dùng vào việc gì — tra biểu phí theo bậc bằng floorEntry, hàng đợi ưu tiên, stack không dùng Stack · List.of, Collections.unmodifiableList, Arrays.asList, List.copyOf và Stream.toList khác nhau thế nào — collection nào thật sự bất biến, cái nào nhận null? · Generics trong Java — type erasure, wildcard ? extends / ? super (PECS), và vì sao List
