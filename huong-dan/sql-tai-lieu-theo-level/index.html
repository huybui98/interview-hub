Tài liệu học SQL theo level

Bộ tài liệu tốt nhất cho từng level Newbie → Junior → Middle → Senior của lộ trình SQL từ con số 0 (PostgreSQL là chính, có phần Oracle cho ngân hàng) — học cái nào trước, đọc phần nào, bài tập ở đâu, miễn phí hay trả phí; mọi link đã kiểm tra ngày 15/11/2026.

Trang này gom tài liệu học của lộ trình SQL từ con số 0 theo từng level, khớp với bộ câu hỏi Newbie · Junior · Middle · Senior. Mỗi level có một danh sách học chính theo thứ tự và các danh sách phụ để luyện tập, tra cứu.

Ký hiệu: ✅ miễn phí · 💰 trả phí (không bắt buộc) · ⚠️ cần kiểm tra điều kiện trước khi dùng. Link kiểm tra ngày 15/11/2026; LeetCode, No Starch, Oracle chặn công cụ kiểm tra tự động nhưng mở bằng trình duyệt bình thường.

Cách chọn và dùng tài liệu

  1. Học trên PostgreSQL, cài bằng Docker như mục "Môi trường học" của lộ trình. Kiến thức chuyển sang Oracle, MySQL, SQL Server được; chỗ khác nhau đã ghi trong từng giai đoạn.
  2. Mỗi lúc một tài liệu chính, kèm một nguồn bài tập. Đọc 30 phút thì gõ 60 phút.
  3. Đoán số dòng trước khi chạy mọi câu SQL — thói quen này quan trọng hơn mọi cuốn sách.
  4. Thứ tự tin cậy: tài liệu PostgreSQL chính thức → sách và site của chuyên gia (Markus Winand, Egor Rogov) → nền tảng bài tập → blog → video, AI.
  5. Ngân sách: phần ✅ đủ tới Middle. Hai cuốn đáng mua nhất: Practical SQL (Newbie) và Designing Data-Intensive Applications bản 2 (Senior).

Newbie

Tương ứng: giai đoạn 1–2 của lộ trình (tuần 1–5). Mục tiêu: đọc và viết SELECT, JOIN, GROUP BY cơ bản; hiểu NULL; tự dựng database mẫu. Câu hỏi: Phỏng vấn SQL — Newbie.

1 SQLBolt ✅ Bài tập tương tác trên trình duyệt Toàn bộ các bài, trong tuần 1 Nhập môn nhanh nhất, không cần cài gì
2 PostgreSQL Tutorial ✅ Tài liệu chính thức Cả 3 chương: Getting Started, The SQL Language, Advanced Features Ngắn, chính thức, đúng phiên bản

4 Select Star SQL ✅ Sách tương tác miễn phí Đọc từ đầu tới cuối Học SQL qua một bộ dữ liệu thật, dạy cách nghĩ
5 PostgreSQL Wiki — Don't Do This ✅ Danh sách thói quen xấu Đọc một lần ở tuần 2, đọc lại ở tuần 5 Tránh học sai từ đầu: money, timestamp không múi giờ, NOT IN…

Luyện tập thêm

  • SQLZoo ✅ — bài tập theo chủ đề.

Sách nếu muốn mua

  • 💰 Practical SQL, 2nd edition (Anthony DeBarros, No Starch, 2022) — sách nhập môn tốt nhất viết riêng cho PostgreSQL, có dữ liệu thật và chương JSON.
  • 💰 Learning SQL, 3rd edition (Alan Beaulieu) — ví dụ chạy trên MySQL, khái niệm dùng chung.

Oracle cho người làm ngân hàng

  • Oracle FreeSQL ✅⚠️ — chạy SQL Oracle trên trình duyệt, thay Live SQL từ 2025; có người dùng báo khó truy cập vào đầu 2026, nên kiểm tra trước khi dựa vào.

Chưa cần ở level này

Index nội bộ, isolation level, partition, replication.

Junior

Tương ứng: giai đoạn 2–4 (tuần 3–11). Mục tiêu: viết SQL đúng trên nhiều bảng, window function, CTE, upsert; thiết kế schema chuẩn hoá; biết index cơ bản. Câu hỏi: Phỏng vấn SQL — Junior.

Học chính, theo thứ tự

# Tài liệu Loại Học phần nào Vì sao chọn
1 LeetCode — SQL 50 ✅ Bài tập phỏng vấn Làm hết 50 bài, chọn dialect PostgreSQL Đúng dạng bài live coding ở vòng kỹ thuật
2 PostgreSQL Exercises ✅ Bài tập Aggregation → Working with Timestamps → Recursive Queries Window, ngày giờ, đệ quy trên dữ liệu thật

4 PostgreSQL Documentation ✅ Tài liệu chính thức Data Definition (constraint), Data Types (numeric, date/time), Queries, INSERT … ON CONFLICT Tra đúng cú pháp và ngữ nghĩa
5 Use The Index, Luke! ✅ Sách web miễn phí (Markus Winand) Hai chương đầu: Anatomy of an Index, The Where Clause Hiểu index trước khi lên Middle
6 "A Simple Guide to Five Normal Forms" ✅ Bài báo kinh điển (William Kent, 1983) Đọc toàn bộ Giải thích chuẩn hoá ngắn và rõ nhất

Luyện tập thêm

  • DataLemur ✅ — câu SQL phỏng vấn, nhiều bài window; một phần miễn phí.
  • HackerRank — SQL ✅.
  • Bộ dữ liệu Pagila ✅ — cửa hàng cho thuê phim, đủ phức tạp để tự đặt đề.
  • dbdiagram.io ✅ — vẽ ERD bằng code khi thiết kế schema.

Sách nếu muốn mua

  • 💰 SQL Antipatterns, Volume 1 (Bill Karwin, 2022) — các lỗi thiết kế hay gặp và cách sửa.
  • 💰 Database Design for Mere Mortals (Michael J. Hernandez) — thiết kế từ nghiệp vụ.

Chưa cần ở level này

MVCC bên trong, WAL, replication, tinh chỉnh tham số server.

Middle

Tương ứng: giai đoạn 4–8 (tuần 9–22). Mục tiêu: đọc EXPLAIN và sửa truy vấn chậm có số đo; hiểu isolation, locking, MVCC; migration an toàn; JPA không N+1. Câu hỏi: Phỏng vấn SQL — Middle.

6 Blog Vlad Mihalcea ✅ Blog chuyên gia JPA N+1, batching, optimistic locking Phần SQL nhìn từ Java/JPA

Oracle cho người làm ngân hàng

  • Oracle Database documentation ✅ — chọn bản đang dùng ở dự án, đọc Concepts (phần transaction, đồng thời) và SQL Language Reference.
  • Oracle Dev Gym ✅ — quiz và workout SQL, PL/SQL miễn phí.

Xem thêm

  • Crunchy Data Blog ✅ — bài PostgreSQL thực tế: index, partition, vacuum.

Sách nếu muốn mua

  • 💰 SQL Performance Explained (Markus Winand) — bản sách của Use The Index, Luke!
  • 💰 The Art of PostgreSQL (Dimitri Fontaine) — SQL cho developer ứng dụng.
  • 💰 High-Performance Java Persistence (Vlad Mihalcea) — nếu đi cùng lộ trình Java.

Chưa cần ở level này

Viết extension, tinh chỉnh kernel, sharding tự làm.

Senior

Tương ứng: giai đoạn 5–9 và phần tổng hợp (tuần 12–26 rồi liên tục). Mục tiêu: quyết định về dữ liệu có số đo — nhất quán, sẵn sàng cao, backup/PITR, sự cố production. Câu hỏi: Phỏng vấn SQL — Senior.
