Phỏng vấn Java Spring Boot — Middle

59 câu lý thuyết và trade-off level Middle (JVM, Spring nâng cao, REST production, JPA và transaction sâu, Oracle ở ngân hàng, Spring Security, test tích hợp, concurrency, Kafka, Docker/Kubernetes, design pattern), 7 câu tình huống, 6 bài thực hành và 1 dự án; mỗi câu có mức ưu tiên, trả lời ngắn, giải thích sâu, code, bẫy và câu đào tiếp.

Level thứ ba của bộ câu hỏi đi kèm lộ trình Java Spring Boot từ con số 0 — tương ứng giai đoạn 5–9 (khoảng tháng 6–11). Trước đó: Newbie · Junior. Sau đó: Senior.

Ở level Middle, câu hỏi chuyển từ "làm thế nào" sang "vì sao, và chọn gì trong hoàn cảnh này". Câu đánh dấu (trade-off) cần trả lời theo khung: ngữ cảnh → lựa chọn → cái giá → khi nào chọn khác. Câu tình huống trả lời theo khung: làm rõ → giảm thiệt hại → tìm nguyên nhân bằng số liệu → sửa gốc → phòng ngừa. Ngân hàng hay hỏi kỹ phần JPA, transaction, đồng thời và Oracle — mục Data dài nhất là có chủ đích.

Mức ưu tiên: Bắt buộc · Nên biết · Nâng cao. Mỗi câu mở ra có đủ năm phần: ⭐ trả lời ngắn, 📖 giải thích sâu, 💻 code, ⚠️ bẫy, 🔁 câu đào tiếp.

Thuật ngữ mới ở level này

Thuật ngữ Nghĩa ngắn
Persistence context Bộ nhớ đệm entity của JPA trong một transaction; theo dõi thay đổi để tự UPDATE
Dirty checking, flush So entity với bản chụp ban đầu; đẩy câu SQL xuống database
N+1 Một truy vấn danh sách kéo theo N truy vấn chi tiết
Propagation, isolation Transaction lồng nhau xử lý thế nào; các transaction đồng thời thấy nhau tới đâu
Optimistic / pessimistic lock Phát hiện xung đột khi ghi (@Version) / khoá khi đọc (FOR UPDATE)
Filter chain Chuỗi filter của Spring Security xử lý mỗi request
Testcontainers Chạy database, Kafka thật trong Docker cho test
Consumer group, partition Cách Kafka chia việc và giữ thứ tự
Circuit breaker Ngắt gọi tạm thời tới service đang lỗi

Qua cửa level Middle

  • ○ Trả lời mọi câu (trade-off) theo khung 4 bước, có ví dụ ngân hàng.
  • ○ Dự án duyệt khoản vay: test 401/403/IDOR, test đếm query, Testcontainers trong CI dưới 5 phút.
  • ○ Trả lời 7 câu tình huống theo khung 5 bước trong ≤ 5 phút mỗi câu.
